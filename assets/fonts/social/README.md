# Fontes das capas sociais

**STIX General** é mantida localmente para que as imagens Open Graph sejam
reproduzíveis, sem rede e com uma assinatura editorial compatível com o site.
O arquivo preserva integralmente os avisos de copyright e licenciamento em seus
metadados. O sans-serif de apoio é o Noto Sans embarcado na versão fixada do
Next.js.

Referências oficiais de origem e licenciamento:

- STIX General: <https://github.com/stipub/stixfonts>
- Noto Sans: <https://github.com/notofonts/latin-greek-cyrillic>

Os arquivos são usados somente pelo gerador em `scripts/generate-social-cards.mjs`.
